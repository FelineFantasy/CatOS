# CatOS 🐱

> 🇬🇧 **English version:** [README.md](README.md)

Жёсткий, минималистичный 16-битный загрузчик операционной системы в реальном режиме, написанный полностью с нуля на ассемблере x86.

```text
       /\_/\
      ( o.o )
       > ^ <   [ Мяу! CatOS загружается... ]
```

📝 Описание

CatOS — это независимый загрузчик, который получает полный контроль над процессором сразу после экрана POST BIOS. Он не полагается на тяжёлые современные загрузчики типа GRUB или сторонние ядра.

### Технические детали:

- 🛠️ **Чистый ассемблер:** Написан на 100% на NASM для 16-битного x86 в реальном режиме.
- ⚡ **Без прерываний BIOS:** Выводит текст чисто, без риска типичных для специфичного оборудования конфликтов очистки экрана на кастомных материнских платах.
- 🛑 **Безопасная остановка:** Реализует строгий цикл `cli` + `hlt`. Полностью отключает аппаратные прерывания, безопасно замораживая CPU в состоянии абсолютного нулевого энергопотребления, предотвращая токсичные циклы перезагрузки.
- 💾 **Жёсткий лимит в 512 байт:** Идеально оптимизирован для размещения в главной загрузочной записи (Сектор 1) с обязательной загрузочной сигнатурой `0xAA55`.

⚙️ Установка и тестирование

Вариант 1: Тестирование в эмуляторе (QEMU)

Убедитесь, что NASM и QEMU добавлены в переменные System PATH, затем просто запустите универсальный ленивый скрипт:

· Windows: Дважды щёлкните build.bat
· Linux/macOS: Выполните ./build.sh

Вариант 2: Запись на реальное железо (Bare Metal)

1. Перейдите в раздел [Releases] и скачайте скомпилированный os.img.
2. Откройте Rufus, выберите вашу USB-флешку.
3. Выберите os.img (переключите фильтр на "Все файлы .").
4. Установите схему разделов MBR, а целевую систему — BIOS (или UEFI-CSM).
5. Нажмите START, перезагрузите ПК, нажимайте F11 и выберите USB-накопитель.
